## 🧩 The Project: FraudLens
An interactive ML web app that classifies credit card transactions as fraudulent or legitimate — trained on the standard Kaggle Credit Card Fraud dataset, deployed live on Streamlit Community Cloud, with a focus on correctly handling class imbalance and explaining predictions in plain English.

## 🧠 Why This Approach
Rather than picking a project first and justifying it afterward, this session inverted the process: constraints (time available, ML experience level, deployment experience) were gathered *first* through a guided interview, and the project was chosen to fit those constraints — protecting against scope creep before a single line of code was written.
