**Date:** [07 July]
**Challenge Day:** 37 / 60
**Category:** Interactive single-file HTML app / Organizational simulation

## Summary
Built "Task Compass," a three-stage management simulation that teaches ownership, delegation, workflow routing, and cross-functional collaboration using café/restaurant scenarios. Fully offline, single HTML file, no dependencies.

## Files
- `task-compass-cafe.html` — the complete app
- `README.md` — project overview
- `LEARNINGS.md` — technical breakdown

## Core Features
- Stage 1: Drag-and-drop ownership assignment (3 scenarios)
- Stage 2: Sequenced workflow routing with animated task flow (3 scenarios)
- Stage 3: Multi-role collaboration assignment for ambiguous problems (3 scenarios)
- Qualitative scoring across 4 dimensions with animated bar chart
- Personalized end-of-shift reflection (strengths, over-assignment patterns, under-collaboration patterns, insight)
