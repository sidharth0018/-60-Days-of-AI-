# Day 38 Prompt

## Goal

Create a premium single-page Typing Speed Studio application.

The AI should first ask the user:

1. Preferred typing category
2. Automatic or customized features

Only after collecting responses should the application be generated.

The application must include:

- Time Mode
- Word Count Mode
- Quote Mode
- Programming Mode
- Adaptive Mode
- Focus Mode
- Zen Mode

Programming practice should support:

- HTML
- CSS
- JavaScript
- Python
- Java
- C++
- SQL
- JSON
- Bash

The application should calculate:

- WPM
- Raw WPM
- CPM
- Accuracy
- Mistakes
- Streak
- Progress

The result page should include:

- WPM Graph
- Accuracy Graph
- Error Heatmap
- Achievement Badges
- Consistency
- Typing Rhythm
- Personal Bests

Store all sessions using Local Storage.

Generate everything inside one HTML file without external libraries.
