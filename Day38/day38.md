# 🚀 Day 38 – Building a Premium AI-Powered Typing Speed Studio

> Part of my **60 Days Claude AI Challenge**

## 📌 Overview

On Day 38, I focused on advanced prompt engineering by designing an enterprise-level prompt capable of generating a complete premium typing application.

Instead of creating a basic typing test, the objective was to instruct the AI to behave as multiple experts simultaneously:

- UI/UX Designer
- Frontend Developer
- JavaScript Engineer
- Performance Engineer
- Educational Game Designer

The result is a specification for a modern typing platform comparable to commercial products such as Monkeytype.

---

# 🎯 Objective

Learn how to write structured prompts that guide an AI through:

- Asking clarifying questions
- Collecting requirements
- Making intelligent feature decisions
- Producing production-quality frontend applications

---

# 🧠 What I Learned

## Multi-role Prompt Engineering

Instead of assigning one role, I combined multiple expert roles inside a single prompt.

Example:

- UI Designer
- JavaScript Developer
- Performance Engineer
- Educational Designer

This dramatically improves the quality of AI-generated applications.

---

## Requirement Collection

The AI was instructed to ask questions before generating code.

Example flow:

1. Select typing category
2. Choose customization level
3. Generate application

This creates a far more personalized application.

---

## Dynamic Prompt Design

Rather than hardcoding one typing paragraph, the prompt requests dynamic generation for different categories.

Examples include:

- HTML
- CSS
- JavaScript
- Python
- Java
- C++
- SQL
- Programming Quotes
- Custom Text

## Feature Planning

Instead of requesting a simple typing test, the prompt defines an entire commercial product.

Features include:

## Real-Time Analytics

The prompt specifies accurate calculations for:

- WPM

- CPM

- Mistakes
