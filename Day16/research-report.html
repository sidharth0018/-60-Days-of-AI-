Key learnings from this session

01

Skill files = reusable SOPs for AI. The /stock-fundamental-research skill encoded source priority, a 20-metric checklist, interpretation thresholds, and output formats — so Claude didn't need to be re-prompted with rules each time.

02

Structured output from noisy data. Claude queried 8+ sources (Screener, Tickertape, TipRanks, Business Standard, BSE filings) and normalized everything into one clean comparison — the core skill in data analytics.

03

Compare mode forces clarity. Putting two companies side-by-side reveals patterns invisible in standalone analysis — like HDFC Bank matching RIL's net profit on 1/3rd the revenue.

04

Research discipline = prompt discipline. Flagging unavailable data, citing every figure, using fixed thresholds (ROE >15% good, <10% weak) — these guardrails prevent hallucination and build trust in AI output.
