1

Weeks 1–4 — Sharpen SQL + Build a portfolio project

Advanced SQL (window functions, CTEs, subqueries). Pick one dataset — fintech, e-commerce — and build an end-to-end analysis in Python + SQL, publish to GitHub.

2

Weeks 5–8 — Dashboard + Statistics

Build a Power BI or Tableau dashboard on your project. Cover statistics basics: hypothesis testing, A/B testing, regression intuition — these come up heavily in interviews.

3

Weeks 9–12 — Apply, case studies, referrals

Target Razorpay, CRED, Groww, Zepto, Juspay. Prep SQL case rounds + product metric questions. Reach out to alumni and use LinkedIn for warm referrals.
