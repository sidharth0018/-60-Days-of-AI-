# Day 45 — Learnings Log

- Turn-gated, single-question interviews force more honest answers than one big upfront prompt — the user can't over-plan their response.
- Deferring all analysis until after data collection prevents the model from anchoring early and biasing later questions.
- Explicitly naming cognitive biases (loss aversion, status quo bias) in the output made the tool feel like a real thinking partner instead of generic motivational text.
- Tight, exhaustive design specs (exact CSS variables, exact section order, exact animation timing) produced a working, polished artifact in a single generation — no revision loop needed.
- Applied this tool to a real personal decision (career focus vs. hedging across paths) rather than a demo scenario, which made the case study authentic for the portfolio.
