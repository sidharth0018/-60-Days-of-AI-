# Day 10 — Personal Portfolio Website with Claude

## Task
Built a complete single-file personal portfolio website using Claude AI
with HTML, CSS, and vanilla JavaScript.

## What I Prompted Claude
- Gave structured input: personal info, skills, projects, design preferences
- Uploaded my resume PDF and profile photo
- Claude auto-extracted details and embedded photo as base64

## Output
- Dark/light mode toggle
- Animated circuit board background (ECE theme)
- Typing animation for roles
- Scroll-triggered skill bars
- Projects, Achievements, Contact sections
- Fully mobile responsive

## Key Learnings
- How to write detailed structured prompts for complex outputs
- Base64 image embedding in HTML
- CSS custom properties for theming
- IntersectionObserver for scroll animations
- Single-file deployment on GitHub Pages
