Day 34/60 of my Claude AI Mastery Challenge 🔍

Most marketing case studies are read once and forgotten. So today I turned one into a game instead.

"Marketing Detective" — you're handed a real-looking campaign: reach, CTR, budget split, customer comments, social sentiment. Numbers look fine on the surface. Something is still wrong. Your job is to find it before the case goes cold.

The actual lesson hiding under the "detective" theme: almost every case follows the same pattern — healthy top-of-funnel metrics (reach, CTR, engagement) sitting next to a broken bottom-of-funnel number (conversion, retention, sales). The skill isn't reading dashboards. It's tracing that gap back to one specific cause — a broken landing page, a missing frequency cap, price anchoring that doesn't match reality, an ad promising something the product doesn't deliver.

Built with React (CDN) + Babel, zero backend, zero database, one HTML file. 12 fully fictional companies, each with a complete data set and a hidden root cause.

This is closer to what campaign post-mortems actually look like than any slide deck I've read — which is exactly why I wanted to build it this way.
