# Day 33/60 — Media Integrity Analyzer

**Challenge:** Build one AI-assisted interactive app a day, for 60 days, and publish it publicly.

## What I Built
A single-file, offline HTML app that teaches media literacy through **guided discovery** instead of a quiz. Users go through two interactive challenges:

1. **Headline Detective** — react to a fictional sensational headline, guess what's misleading, then reveal a Headline Accuracy Score, flagged phrases, a fair rewrite, and the "why."
2. **Emotion Detector** — read a fictional social post, name your own emotional reaction, tag the trigger words, then reveal the manipulation technique, target audience, and a neutral rewrite.

Live metrics (Headline Accuracy, Source Reliability, Emotional Manipulation, Audience Targeting) update as you go, ending in a personal **Media Integrity Dashboard** with an overall score, key learnings, biggest red flag, three practical habits, and a Replay option with fresh scenarios.

## Stack
Pure HTML + CSS + vanilla JS. Zero dependencies, zero APIs, zero images — works fully offline in one file.

## Design
Premium editorial dark theme in **Claude Orange** — serif content typography, animated step progress, hover-interactive cards, and a fully responsive layout.

## Why This Matters
Media literacy is normally taught as "spot the fake news" trivia. This app instead makes you *feel* the manipulation first (would you click? how did this make you feel?) before showing you exactly how it was engineered — which is a much stickier way to build a lasting habit of pausing before reacting online.

## Key Takeaway
Instructional design principles (concept → why it matters → real-life relevance → guided reveal) translate directly into better UX patterns for any learning tool — a pattern I'll reuse for future data-literacy or interview-prep apps in this challenge.
