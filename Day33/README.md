# Day 33 — Media Integrity Analyzer 🔎

Part of the **ABTalks 60-Day Claude AI Mastery Challenge**
One AI-assisted interactive app, every day, published to GitHub + LinkedIn.

## 🎯 What This Is

A single-file, offline-first web app that teaches **media literacy through guided discovery** instead of testing prior knowledge. Users read a fictional headline and a fictional social post, form their own reaction first, and then unlock a full breakdown: accuracy scores, manipulation techniques, highlighted red-flag phrases, fair rewrites, and a final personal integrity dashboard.

The pedagogy is deliberate: **observe → predict → reveal → reflect**, rather than quiz-and-grade. This mirrors how real critical-thinking habits are built — by noticing your own reaction to manipulative content in the moment, not by memorizing rules in the abstract.

## ✨ Features

- **Challenge 1 — Headline Detective**: Analyze a fictional sensational headline vs. its calmer source article. Predict if you'd click, guess the misleading phrase, then reveal a Headline Accuracy Score, highlighted mismatches, a fair rewritten headline, and a key takeaway.
- **Challenge 2 — Emotion Detector**: Read a fictional social/influencer post, name your own emotional reaction, tag the phrases that triggered it, then reveal the target audience, intended emotion, manipulation technique, a neutral rewrite, and a takeaway.
- **Live Media Integrity Metrics**: Headline Accuracy, Source Reliability, Emotional Manipulation, Audience Targeting — animated bars that populate as you progress.
- **Final Dashboard**: Overall Media Integrity Score, what you learned, your biggest red flag, three practical daily habits, and a **Replay** button that reshuffles entirely new scenarios.
- **Zero dependencies**: pure HTML/CSS/JS in one file, no build tools, no APIs, no images, works fully offline.

## 🎨 Design

Premium editorial dark theme in **Claude Orange**, built with:
- Serif editorial typography for article/headline content, clean sans-serif UI chrome
- Animated progress bar + step tracker across the 8-stage journey
- Smooth `fadeUp` / `fadeDown` transitions between stages
- Hover-interactive cards, chips, and metric tiles
- Fully responsive grid (desktop 4-column metrics → mobile 2-column)

## 🛠️ Tech Stack

- HTML5
- Vanilla CSS3 (custom properties, grid, flexbox, keyframe animation)
- Vanilla JavaScript (no frameworks, no build step)

## 🚀 How to Run

1. Download `media-integrity-analyzer.html`
2. Open it directly in any modern browser
3. No server, no install, no internet connection required
